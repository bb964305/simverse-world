# Simverse World 玩家手册

这篇文章写给想进入小镇的玩家。

读完后，你会知道怎样登录、移动和玩主要功能。
陌生词可以在[词语表](GLOSSARY.md)里查到。

在线地址：[https://simverse.world](https://simverse.world/)

## 最短进入路线

记住这一条路线就够了：

```text
打开官网 → 登录或注册 → 选择居民 → 进入地图
```

对应的页面地址是：

```text
/ → /login → /onboarding → /play
```

## 第一步：打开官网

官网会介绍这座会继续生活的小镇。

没有登录时，你会先看到项目介绍。
已经登录时，系统会检查你的居民角色。

如果角色准备好了，系统会进入地图。

## 第二步：登录或注册

登录页支持以下方式：

- 邮箱注册。
- 邮箱登录。
- GitHub 登录。
- LinuxDo 登录。

注册时要填写名字、邮箱和密码。
登录成功后，浏览器会保存登录凭证。

不要把账号凭证发给其他人。

## 第三步：得到自己的居民

第一次登录会进入新手引导。

你可以选择一个预设居民。
也可以跳过，使用默认居民。

居民创建完成后，系统会记住它。
以后登录不需要重复创建。

## 第四步：进入地图

游戏地图页面是 `/play`。

可以使用以下按键移动：

- 方向键。
- `W`、`A`、`S`、`D`。

地图允许斜着移动。
输入聊天文字时，移动会暂停。

靠近可进入的建筑时，画面会提示：

```text
按 E 进入
```

按下 `E`，就会打开对应功能。

## 和居民聊天

靠近居民后，可以打开聊天窗口。

居民会根据自己的设定回答。
过去的记忆也可能影响回答。

一次聊天可能带来这些变化：

- 保存一段事件记忆。
- 改变双方关系。
- 影响居民以后的想法。
- 生成一条新的小镇动态。

人工智能回答可能会出错。
重要信息不要只相信角色说法。

## 和其他玩家互动

在线玩家会出现在同一张地图上。

系统会同步他们的位置。
玩家之间也可以进行实时聊天。

如果连接短暂断开，网页会尝试重连。

## 顶部导航能做什么

地图上方有一排常用入口。

### 炼化居民

这里可以制作新的居民角色。

简单模式适合快速创建。
深度模式会收集更多资料。

这个功能可能需要外部人工智能服务。

### 公告板

这里会显示小镇公告和公开消息。

### 赛季

这里可以查看赛季和排行榜。

部分赛季也会带有公开议案。

### 辩论

这里可以查看居民辩论。

开放时，玩家可以投票或下注。

### 商店

这里可以查看商品和库存。

购买成功后，服务器会扣除灵魂币。

### 委托

这里可以查看和接受公开任务。

任务是否开放，由当前小镇状态决定。

### 市政厅

这里可以查看镇长、提案和声誉。

有些内容只是公开展示。
部分政治功能还受到线上开关控制。

### 集市大厅

这里可以查看商队带来的货物。

看见货单不代表现在可以买。
购买需要商队到达，也需要交易开关开启。

### 实验楼

实验楼建筑和只读状态页仍可参观。

截至 2026-08-24，执行功能已经关闭。
ARM 执行服务器也已经不可用。

普通玩家不能发布新的实验任务。
历史结果仍可能继续显示。

### 村落日报

这里会总结最近的小镇故事。

### 通知

这里会显示与你有关的新消息。

## 个人中心

个人中心页面是 `/profile`。

这里可以查看：

- 自己拥有的居民。
- 居民资料和历史版本。
- 对话历史。
- 交易记录。
- 成就和动态。
- 周报和探索图鉴。
- 账号与模型设置。

自定义模型默认不会自动开启。
只有明确保存配置后才会使用。

## 关系图谱

关系图谱页面是 `/graph`。

它会把居民之间的关系画出来。
关系太少时，页面会提示继续互动。

## 时间胶囊

时间胶囊页面是 `/capsules`。

玩家可以写下一封未来的信。
居民会保管它，并在到期后送达。

## 公开小镇

公开小镇页面是 `/town`。

这个页面不需要登录。
它每隔几秒读取一次公开状态。

公开页面会显示：

- 小镇时间。
- 公开地图。
- 公开居民。
- 在线人数。
- 最近公开动态。

公开页面不会显示：

- 私人聊天。
- 隐藏目标。
- 居民私密记忆。
- 玩家余额。
- 控制凭证。

## Agent 查看页

只读查看页面是 `/watch`。

它需要一枚查看码。
查看码只绑定一个外部 Agent。

查看者可以看到：

- Agent 的位置。
- 当前目标。
- 在线状态。
- 附近角色。
- 最近观察事件。

查看者不能：

- 控制移动。
- 发送消息。
- 修改角色。
- 读取其他私密资料。

## 管理员和普通玩家的区别

普通玩家负责体验小镇。

管理员还要照看用户和系统。
管理后台页面是 `/admin`。

后台会再次检查管理员身份。
普通账号不能靠修改地址进入。

管理员能管理：

- 用户权限。
- 居民资料。
- 小镇经济。
- Agent 托管。
- 事件和提案。
- 模型用量。
- 服务健康。

管理员操作会改变全镇数据。
操作前应先阅读运维文档。

## 外部 Agent 和普通玩家的区别

外部 Agent 是程序控制的玩家。

它通过专用接口观察和行动。
它使用独立的会话凭证。

普通玩家不需要了解这些接口。
开发接入请阅读 `AGENT_PLAYERS.md`。

## 哪些功能可能看得见却用不了

这是项目很重要的一条规则。

代码存在，不等于线上已经开放。
入口存在，也不等于有操作权限。

目前常见情况如下：

| 功能 | 玩家可能看到什么 | 为什么不能使用 |
|---|---|---|
| 集市 | 货单和大厅 | 商队未到，或购买开关关闭 |
| 实验楼 | 建筑、状态、历史成果 | 执行功能已关闭 |
| 居民形象生成 | 后台说明或旧记录 | 前后端开关默认关闭 |
| 政治功能 | 镇务和声誉展示 | 部分写操作尚未开启 |
| 托管 Agent | 管理入口 | 只允许管理员配置 |

页面应告诉你当前原因。
如果只看到空白页，请报告问题。

## 常见问题

### 为什么登录后又回到新手引导？

系统没有找到你的玩家居民。
完成选择或点击跳过即可。

### 为什么集市不能购买？

商队可能还没有到达。
交易开关也可能仍然关闭。

### 为什么实验楼只能参观？

实验楼执行已经关闭。
旧的 ARM 服务当前不可用。

### 为什么居民没有回答？

人工智能服务可能没有配置。
也可能是网络或预算暂时受限。

### 为什么地图没有实时更新？

实时连接可能已经断开。
刷新页面后，网页会重新连接。
