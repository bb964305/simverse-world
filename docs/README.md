# Simverse World 文档目录

这里是项目文档的总入口。

不用一次读完所有文件。
先选择你现在要做的事。

## 请选择一条路

- [我要玩](#玩家路径)：了解小镇，再进入游戏。
- [我要开发](#开发者路径)：启动代码，再学习修改和验证。
- [我要运维](#运维路径)：安全发布，再学习检查和恢复。
- [查看全部文档](#全部文档)：查找管理员、外部 Agent（接入小镇的程序玩家）、计划、报告和历史资料。

每条主路径都有清楚的终点。

玩家不需要阅读部署命令。
运维人员也不用先读玩法细节。

遇到陌生词时，可以稍后查看词语表。

带日期的计划和报告是当时的记录。
它们不一定代表项目现在的状态。

当前状态只看当前路线图。

下面从六条固定阅读路径开始。

## 文件怎么归类

以后新增文档时，请放到对应位置：

| 内容 | 位置 |
|---|---|
| 当前新手说明 | `docs/` 根目录 |
| 实施步骤 | `docs/plans/` |
| 调查或生产证据 | `docs/reports/` |
| 可按顺序执行的生产操作 | `docs/runbooks/` |
| 产品和视觉设计 | `docs/design/` |
| 宣传制作稿 | `docs/marketing/` |
| 不再代表当前状态的资料 | `archive/` |

新增文件后，也要更新这个目录。
