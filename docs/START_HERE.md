# 第一次认识 Simverse World

这篇文章写给第一次看到项目的人。

Simverse World 是一座在线小镇。
小镇里的居民会继续生活和记事情。

读完后，你会知道三件事：

1. 玩家在小镇里做什么。
2. 居民为什么会自己行动。
3. 项目的几个部分怎样合作。

遇到陌生词时，请查看[词语表](GLOSSARY.md)。

## 先把它想成一座小镇

假设你走进一座像素小镇。

你能看见房子、商店和居民。
居民不是站着不动的木偶。

他们会走路、工作和聊天。
他们也会记住发生过的事情。

当玩家离线时，小镇不会消失。
后台程序会让小镇继续变化。

这就是项目最重要的想法：

> 这是一座会继续生活的数字小镇。

## 你进入小镇以后

第一次进入时，你要先登录。

接着，你会得到自己的居民角色。
你可以选择预设角色，也可以跳过选择。

进入地图后，你可以：

- 在小镇里移动。
- 和居民聊天。
- 认识其他在线玩家。
- 查看公告和小镇新闻。
- 参加赛季、辩论和镇务活动。
- 使用商店、委托和集市。
- 制作新的居民角色。

有些功能会按安全开关开放。
所以，看见入口不等于功能已经开放。

例如，实验楼目前只保留参观。
它的任务执行功能已经关闭。

## 小镇居民有什么特别

每位居民都有自己的设定。

设定包含性格、经历和能力。
这些内容会影响居民怎样说话。

居民还会保存三类记忆：

1. 发生过什么事情。
2. 自己和别人是什么关系。
3. 自己从经历中想明白了什么。

人工智能会帮助居民理解文字。
项目把这种技术叫作 AI。

AI 不会独自决定所有规则。
金币、权限和数据仍由服务器检查。

## 玩家、居民和管理员

### 玩家

玩家是真正使用游戏的人。
玩家控制自己的角色并参加活动。

### 居民

居民是生活在小镇里的角色。
部分居民由程序长期控制。

### 管理员

管理员负责照看整个小镇。
他们可以查看健康、用户和经济状态。

管理员还能控制危险功能的开关。
普通玩家不能进入这些管理区域。

### 外部 Agent

外部 Agent 是接入小镇的程序玩家。
它可以观察世界，并按规则行动。

它和普通玩家使用不同的接入方式。
详细内容属于高级开发资料。

## 项目背后的四个部分

### 第一部分：网页和游戏画面

这是玩家能看到的部分。

它负责地图、按钮、聊天和动画。
代码主要放在 `frontend/` 目录。

### 第二部分：小镇服务器

这是处理规则的部分。

它检查登录、金币、角色和权限。
代码主要放在 `backend/` 目录。

### 第三部分：数据仓库

它保存小镇的重要资料。

用户、居民、记忆和交易都在这里。
临时消息则交给一个快速消息站。

### 第四部分：后台工人

这些程序没有游戏画面。

它们让居民行动，也执行定时任务。
所以，小镇能在玩家离线时继续变化。

## 一次操作是怎样完成的

以“打开市场”为例：

1. 玩家点击市场按钮。
2. 网页向服务器询问市场状态。
3. 服务器读取数据库。
4. 服务器把结果交回网页。
5. 网页显示货物或关闭说明。

实时移动使用一条持续连接的通道。
这样，画面不必反复刷新。

## 这个项目不是什么

它不是只有一页画面的展示网站。

它也不是只会回答问题的聊天机器人。

它有地图、角色、规则和长期数据。
很多功能还会受到权限和开关保护。

旧计划也不等于当前功能。
项目当前状态只看现行路线图。
