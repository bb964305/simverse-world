## 1. 阶段定义与优先级逻辑

| 阶段 | 主题 | 为什么在这个位置 |
|---|---|---|
| **S0 前置** | 部署、数据画像、时间尺度、人口规模 | 不做则后面全部悬空:REALISM/M 批次还没烧机,SBTI 画像缺失使一切个体差异失效,11 人撑不起派系统计;世界时钟同时是任期节律、年龄增长、承载节律的前置 |
| **S1 社会地基** | 声誉、舆论、经济闭环 | 权力的"代价环"全部依赖声誉与舆论;财政闭环是裁量权的弹药 |
| **S2 权力核心** | 职位、裁量点、问责、政策表 | 最小权力环:来源(已有)+ 行使 + 代价三环闭合;政策表是后续一切规则博弈的舞台 |
| **S3 雅典化** | 抽签、轮值、集会、审计、陪审 | 在 S2 的职位/政策骨架上换填充策略,成本低、叙事收益高 |
| **S4 负面机制** | 证据、丑闻、操纵、腐败行为 | 需要 S1 的暴露面(声誉/舆论)和 S2 的收益面(裁量/财政)都就位才有戏剧性 |
| **S5 深水区** | 实验楼机构化、健康生死、玩家入镇、放逐、人口、文化历史、开放性 | 依赖最多、单体最大,或戏剧性最强但需要全部兜底机制先在 |

## 3. 实验楼专章:镇政府下属政策机构

### 3.1 定位与权力拓扑

实验楼隶属镇政府,是**政策制定机构**:接收公民建言、起草合规议案、运行限时试点、发布统计公报、保管修订档案。隶属关系带来的张力从"收买 vs 独立"移到"**政治任命 vs 专业官僚**":研究员是事务官,镇长换届他们仍在;抵抗形态是拖延执行、选择性汇报、辞职抗议、向记者泄密。实验楼预算走镇财政(S1-5),镇长财政排序权(S2-2)天然是缰绳;实验楼主任为 offices 表职位,**镇长提名 + 轮值议事会确认**——"换一个听话的主任"要付政治成本。

### 3.2 五层修改面(L0–L4)

| 层级 | 内容 | 实验楼能力 | 程序 | 护栏 |
|---|---|---|---|---|
| **L0 工程安全层** | Lab 审批门、安全不变量、LLM 预算/模型、系统开关、玩家数据、遥测 | **绝对禁区** | — | 白名单里根本没有这些 kind(物理不可达,非高门槛) |
| **L1 物理空间层** | 地图、建筑、dynamic_locations、地点属性 | **已有能力,保持** | Lab 提案 → preflight → 审批 → apply(现有全套,含 revert) | 爆炸半径限制、可逆性强制 |
| **L2 政策层** | policies 表全部条目 | **只有起草权与背书权,无直接修改权** | 起草成合规议案后走 §3.3 分级审批;研究报告作为舆论(S1-3)高权重输入 | 实验楼直接改政策会让暗渠吞掉明渠;其政策影响力必须以"科学权威"形态过舆论这道手 |
| **L3 自然法则层** | REALISM 参数限定子集:记忆衰减 τ、八卦传播概率、偶遇权重、天气倾向、需求代谢率、移动速度 | **核心新增能力:信封内限时试点** | "试点"程序:有假设、有期限、限域(可按地区),到期**自动 revert**,转永久必须走公投明渠 | WorldGuard 信封(每参数 min/max + 单次步长 + 冷却 + 月度预算,照抄 PersonalityGuard 范式) |
| **L4 心智生命层** | 居民记忆写入/删除、人格直接改写、居民创造删除 | **默认禁区;只读研究开放**(读记忆做统计) | 写入若剧本季需要,单独立项 + 宪法核心级门槛 | 这一层的滥用不是腐败是恐怖故事,留给剧本季刻意使用 |

L2/L3 的不对称是暗渠的全部价值:公投改**看得见的规则**(政策贴在市政厅),实验楼试点改**看不见的物理**(丑闻记忆衰减快 30% 没有公告)。镇长施压实验楼的动机由此成立:让丑闻消退更快、让自己在偶遇采样里权重更高、让集会日多下雨——单条都在信封内,合起来才是统治术。

### 3.3 分级审批矩阵(路由规则本身入政策表,置绝对多数级)

| 事项 | 审批主体 | 例子 |
|---|---|---|
| 行政级 | 对应管理者 / 镇长直批 | 活动核准、小额拨款、物理小改动(修路、加长椅) |
| 简单多数级 | 公民投票 | 税率、宵禁、营业规范、建设项目、医疗补贴 |
| 绝对多数级 | 公投高门槛 | 选举间隔、罢免门槛、**审批路由规则本身**、住房开发规模 |
| 宪法核心 | 不可修改 | 选举存在、放逐权、实验楼审批门、信封定义、**实验楼不得修改管辖自身的规则**(自指保护) |

公民建言入口:居民与玩家均可提(M3 advisory propose 现成),起草合规科整理成结构化议案——**起草排期权是天然微腐败点**。把公投事项悄悄划进行政直批 = 最高级夺权手法,由违宪控告(S3-7)管辖。

### 3.4 四科室(全部是现有工程件的虚构层命名)

| 科室 | 职能 | 对应工程件(已存在) |
|---|---|---|
| 起草合规科 | 公民建言 → 结构化议案、合规审查 | **Proposal Compiler 全管线**(draft→验证→compile→preflight;kind/字段白名单即"合规审查") |
| 试点科 | L3 参数限时限域试验 | world revision + revert + WorldGuard 信封 + 日落条款 |
| 统计公报科 | 汇总运行指标、发布公报 | **burnin 探针体系**(政体快照、物价、基尼、扩散半衰期) |
| 档案与内审科 | 修订留痕、审计证据源 | revision log + **Verifier worker**(工程上只读无写权限 = 制度上不可收买的内审员) |

### 3.5 三层信息视图(本计划最重要的信息纪律)

| 视图 | 受众 | 内容 | 性质 |
|---|---|---|---|
| **精确仪表盘** | **仅玩家**(实验楼终端交互) | 政体曲线、财政、物价、基尼、舆情、扩散状态、进行中试点(参数/期限/续期次数) | 上帝面板;全玩家可读,提案设小额费用或声誉门槛防刷 |
| **公报** | 居民(世界内信息物) | 聚合、延迟、**可被操纵**的定性结论("本季物价平稳") | 可传播、可失真、可造假 → **统计美化**腐败机制;官方数字 vs 居民体感背离 → 八卦素材与信任侵蚀 |
| **prompt 隔离** | 工程纪律 | **全局指标永不进入任何 NPC prompt**,唯一例外是公报机制 | 写成测试断言,与"零新增 LLM 调用"同级纪律;否则 P2 信息梯度全部投资归零 |

### 3.6 隶属关系下的腐败菜单与对抗力

四种升级形态:**行政施压**(直接下令留痕最少,但研究员怨恨积累→泄密概率上升)、**统计美化**(§3.5)、**路由操纵**(改审批分级)、**试点永久化**(到期反复续期,"临时措施长期化"——续期留痕正是记者的天然选题)。对抗力:议事会确认与质询、Verifier 内审的工程级只读独立性、记者调档、居民体感这个永远造不了假的底层信号。另:实验楼统计科能**看见**恩庇率与政体曲线——"发现镇长腐败数据,发表还是压下"的困境自动出现,零额外代码。

### 3.7 红线重申

隶属关系只存在于虚构层。信封、日落条款、审批门、Verifier 只读性全部在工程层,不随组织架构改变——镇政府管着实验楼,但管不到物理定律的边界。本节同时是 LAB_REMAINING 遗留项 "capability profiles"(P3 part 4)的设计输入:L0–L4 分层 = profile 枚举。

## 4. 健康、生命周期与玩家入镇专章

设计总纲:**死亡必须有预兆、有过程、有去处**——突然死亡读作 bug,缓慢衰弱才读作生命;"去处"既是空间的(医院、墓地),也是叙事的(葬礼、镇志、讲古)。

### 4.1 健康机制(S5-8)

health 是以天/周为单位漂移的**慢变量**,与三需求(tick 级快变量)时间尺度分开,互不污染。全部纯规则:

- **输入面**:年龄基线(越老风险越高)、需求长期荒废(连续多日低饱腹/低精力缓慢侵蚀——"不好好生活"有了后果)、天气暴露(暴风雨天在户外)、低概率事故(天气调制)、长期情绪(慢性负 valence 侵蚀健康,心身关联,给情绪环加一个下游)。
- **状态机**:健康 → 不适(轻 debuff,咳嗽/请假外显)→ 患病(居家或就医)→ 重症(住院)→ 康复 / 死亡。每级都有可观察外显 = "预兆"。
- **医疗与社会接口**:看病要钱 → 穷人小病拖成大病 → **医疗可及性是最锋利的不平等探针**(治疗率 × 财富分位相关性);"医疗补贴"进政策表,健康升格为政治议题。**诊所随初始地图播种**(机制冷启动),**医院走 M5 治理建设**——"要不要建医院、钱从哪来"是比邮局剧院更有张力的议案。医生为新 duty + office:全镇病情秘密的知情者,医密是他的声誉考验、八卦系统的富矿。探病行为长在现有走访动作上,是关系深化与"告别窗口"的载体。
- **瘟疫(选做,留剧本季)**:沿偶遇/关系网络的接触传染——复用 P2 的图,传染病学与信息扩散同构;封锁与否是政治。

### 4.2 年龄与退休

全员(居民+玩家)加 `age` 属性,随世界时钟增长(**强依赖 S0-3**,否则是装饰数字)。消费端:健康基线、工作产出微调、**退休**(老居民卸任 duty → 岗位空缺 → 接任命权与人口迁入,闭环)、长者地位(讲古行为的天然主体)。玩家选龄 >18(同时满足内容红线);**轻机制、不重数值**——影响健康基线、外观提示、prompt 自我认知,不给初始资源加成(防"最优开局年龄"式 meta 化)。

### 4.3 死亡管线与继承(S5-9)

完整链路:重症住院 → 亲友探病(告别记忆)→ 死亡事件 → 葬礼(关系网聚集,生命事件)→ **遗产**(有亲属给亲属、无亲充公镇财政;**遗产纠纷是陪审法庭的天然案源**)→ 墓地落位(新地点,扫墓微行为选做)→ 镇志条目 → 讲古素材。

**NPC 死亡节奏纪律**:限老年、长病铺垫、绝不随机秒杀——玩家对老 NPC 的感情是真实资产,死亡要成为剧情而不是事故;死亡释放的名额由迁入补上,人口动态完整。事故死亡留给剧本季刻意使用。

**玩家死亡 = 转世方案(已拍板)**:死亡后灵魂档案保留,以新身份归来、带记忆断层——点"赛博永生"的题,与 v2.0"20 转世灵魂 + 记忆断层 + 附身"严丝合缝,玩家死亡是那套远景机制的入口。落地前过渡期采用**软死亡**(重症必被抢救,代价为医疗债)。

### 4.4 玩家入镇流程(S5-10)

1. **选龄**:Onboarding(v1.1 现成流程)加一步年龄选择,>18。
2. **入口 spawn**:新玩家出生点固定为小镇入口(地图需定义 gate 位置)。
3. **引导员巡游**:文书处/民政派遣**临时 NPC**(S5-7 访客服务的第一个消费者):入口迎接 → 固定 waypoint 路线(广场、商店、酒馆、市政厅、实验楼、医院……)→ 每站一段介绍 = 教程节拍,直接挂**探索图鉴(E8,已交付)**解锁 → 走完离镇 despawn。工程要点:巡游是**脚本化护送行为**,不走自主 AgentLoop;对话全模板 + 向导 persona 着色,零 LLM(可选一次调用按玩家 Forge 人设生成个性化开场白)。**一周后向导通过邮局寄一封模板信**("听说你在镇上安顿下来了")——归化期孤独感的零成本点睛。
4. **边界情况**:掉线(向导下一站等 N 分钟后离镇,巡游可从图鉴续)、玩家乱跑(向导在下一 waypoint 等待 + 小地图标记,不做跟随)、并发新玩家(每人一个向导,设并发上限排队)、跳过(允许,向导提前离镇)。
5. **客籍期 → 归化**:玩家走 S5-4 同一套客籍制(可打工/交易/聊天,不可投票任职,nameplate 客籍标记),归化时办小仪式(大会欢迎新公民,八卦素材)。**制度上玩家和迁入 NPC 同轨**——这是"玩家是居民而非游客"的落点。

### 4.5 拍板记录(2026-07-24)

玩家死亡:**转世为主方案,过渡期软死亡**;医院:**诊所播种 + 医院治理建设**;NPC 死亡:**基础版只开老年+长病路径,事故死亡留剧本季**。均按建议采纳,可随时改。

## 5. 承载与扩容专章

### 5.1 四条上限(按现行参数与既有研究)

| 维度 | 当前上限 | 依据 |
|---|---|---|
| **LLM 吞吐** | **~86 居民**(5% 互聊率打满并发);计划优先跳 decide 等优化生效后 **~200+** | E-13 排队模型:tick 60s × 信号量 5 = 每轮 300 并发秒;decide ~2s、互聊 ~30s |
| **LLM 成本** | 15 居民 ≈ $0.9/天,100 居民 ≈ $185/月(Haiku 列表价);**熔断预算默认 $1.5/天,实际只授权 ~15–25 居民** | COST_RESEARCH_REPORT + `budget_global_daily_usd=1.5`(按 15 居民基线 ×1.5 设定) |
| **空间** | 128×180 地图、20 命名地点、住房挂 `home_location_id`——**住房存量是物理上限** | 地图数据 + v1.4 居民住房 |
| **叙事** | **~50 人是"小镇感"天花板**(玩家记不住人、八卦池稀释、日报盖不住);**政治层最佳规模 25–40** | 社会认知约束,非工程约束 |

**关键错位**:吞吐上限(86)远高于预算上限(~20)——**当前真实瓶颈是 $1.5 的日预算,不是架构**。扩到 25–40 人只需预算调到 **$3–5/天**,架构不动。

### 5.2 超载行为(现状,分级变笨而非崩溃)

预算熔断三档已交付:80% → 背景降频(tick ×2、plan 转 48h);95% → 背景全规则化(decide 不调 LLM、互聊暂停);100% → 只保玩家可见调用。吞吐超载表现为均匀减速(信号量排队拉长实际 tick 间隔,200 居民@10% 互聊 ≈ ×3)。**超载的真实代价是拟真度而非可用性**:tick 拉长先打碎作息节律(REALISM P1 昼夜节律探针先报警),熔断 95% 档时居民集体退化为规则木偶。承载量的正确定义不是"多少人不崩",是"多少人还像个小镇"。

### 5.3 承载的世界机制化(推荐方案)

迁入本来就是拉动式的(S5-3:岗位/住房空缺才触发铸造),人口在构造上不可能超过"住房+岗位"总量。顺此:

- **住房存量 = 世界内承载上限**;扩容 = 建新房 = M5 治理建设,要花镇财政、要过议案——**小镇的承载量由小镇自己投票决定**(现实小镇的 zoning 之争)。
- **超载表现全部内化**:接近上限时房租上涨(S1-6)、医院床位紧张(§4.1 床位 = 第一个容量型公共品)、餐馆排队(地点 capacity 现成)、岗位竞争;压力超阈值 → 不满居民迁出。人口自然走 logistic 曲线,在承载线附近自平衡,无需硬编码人口管制。
- **工程兜底**:config `POP_MAX`(建议 40)做最后防线;触顶时 MigrationService 停止铸造、迁入排候补名单("镇上住不下了"本身是叙事素材)。

### 5.4 远景扩容路线(标记为"不急")

若要 100+ 居民:**分级模拟(LOD)**——玩家附近/高热度居民跑完整五阶段认知管线,后台居民跑纯规则统计管线(吃饭睡觉上班,不调 LLM),按玩家距离与 heat 动态升降级。E-18 已证模型无档可降(全 Haiku),但**频率与管线深度有档可降**;加并发信号量扩容与 worker 拆分(P0-3a 预留),200+ 可达。但 50 人以内的浓度才是产品的味道,人多先死的是叙事。

### 5.5 容量参数汇总(单一事实源,进 config)

| 参数 | 建议值 | 说明 |
|---|---|---|
| `POP_MAX` | 40 | 工程硬顶,正常由住房软机制先兜住 |
| 住房存量(地图数据) | 初始 ≈30 户 | 扩建走治理;= 世界内软上限 |
| 医院床位 | 诊所 2 / 医院 6 | 容量型公共品;紧张度进公报与议案素材 |
| `budget_global_daily_usd` | 25–40 人 → $3–5 | 现值 $1.5 只够 ~20 人;随人口调整 |
| `agent_max_concurrent` | 5(现值,86 人内够用) | 超 86 人先扩并发/拆 worker 再谈成本 |
| 引导员并发上限 | 3 | 超出排队,新玩家先自由活动 |

## 8. 完善点(第五轮新增,8 项)

**8.1 玩家在权力体系中的位置。** 玩家默认可投票、可被八卦;担任职位从小职位(抽签)起步、竞选镇长需声誉门槛;玩家行使裁量权走同一套三落库纪律与丑闻管线——**玩家腐败也会败露**,用制度而非管理员防 griefing。"被抽中当司库"做成 opt-in 推送,是极好的留存钩子。(玩家入镇与客籍已在 §4.4 展开。)

**8.2 判决执行器标准化。** 统一惩罚执行层:罚款(钱包/财政划转)、声誉罚、禁足(N 天不得进入某地点)、撤职(offices 表)、放逐(S5-2)。避免每个司法机制各写一套后果代码。

**8.3 市政厅面板。** 已展开为 §7.1 首行,是整套系统的产品化出口。

**8.4 多镇对照 burn-in。** burnin 框架支持同配置不同种子 / 同种子不同开关的多镇并行,输出政体曲线对比;吸收态检测做成告警而非事后分析。

**8.5 剧本季与涌现政治的仲裁规则。** 涌现状态优先,剧本只能通过合法渠道注入("X 宣布参选"而非"X 就是镇长"),否则政治因果链被反复打断。

**8.6 政治记忆的重要度规则。** 投票、庭审、丑闻、放逐、**死亡与葬礼**在 memorize 阶段按事件类型加 importance(闪光灯效应),防止大事件被日常闲聊淹没导致问责环失效。

**8.7 LLM 成本例外清单。** 全表仅六处:社团起名(一次/社团)、编年史(一次/季)、迁入铸造(一次/人)、临时访客(轻量)、**向导个性化开场白(可选,一次/新玩家)**、记忆失真(选做)。config 为各项单设预算计数器,守住"政治层零边际成本"。

**8.8 政治史叙事输出。** 政体快照 + 镇志合成自动"政治史时间线"(当选/议案/丑闻/放逐/**生卒**),同时供玩家端(讲古/图鉴)与运营端消费。

## 9. 红线清单

1. **Lab 工程安全不变量不动**:虚构层合谋只影响"实验楼想提什么",永不绕过真实审批门与权限体系;L0 物理不可达。
2. **防吸收态**:宪法核心不可修改 + 违宪控告 + 试点日落条款 + 放逐安全阀 + 外部冲击。"被捕获"是可观察、可反抗、可能长期维持的状态,不是游戏结束画面。
3. **prompt 隔离**:全局指标永不进入 NPC prompt,唯一例外是公报(世界内信息物);写成测试断言。
4. **不移植历史黑暗面**:奴隶制、排除女性跳过;客籍制必须有归化通道;**玩家年龄 ≥18,全员角色均为成年人**。
5. **死亡纪律**:NPC 死亡必须有预兆、有过程、有去处——限老年+长病铺垫,绝不随机秒杀;每例死亡应留下告别记忆与镇志条目。
6. **随机可复现**:抽签、暴露概率、陪审抽选、健康事件全部注入 RNG + seeded 测试。
7. **门控习惯**:每模块独立开关默认 False,关闭时既有测试零改动通过。
8. **美术纪律**:provenance 登记 + release 门 fail-closed + $visual-verdict 流程,不生成占位图冒充美术。
9. **承载兜底**:`POP_MAX` 硬顶 + 预算熔断分级是最后防线;正常情况下由住房/岗位的世界内软机制先兜住(§5.3)。
