### Task 7: 移动提速与通勤感知（§3.1A）
- `execute/basic.py`：realism on 时沿 path 走 `_effective_speed(base, weather_kind, arousal)` 格（叠乘 rain0.75/storm0.5/snow0.6，arousal>0.7 ×1.2，min 1），取 `path[min(speed, len(path)-1)]`；到达 target→idle。weather 从 `ctx.world_events`（type=="weather"）取，arousal 从 `resident.mood_json`。off→单格（现状）。

- 测试：单 tick 位移 ≤ speed；storm 下 speed 减半；到达即 idle。前端四连。

### Task 8: 天气影响行为（§3.2）
- `scheduler.get_activity_probability(schedule, hour, weather_kind=None)`：realism 时 `p ×= WEATHER_ACTIVITY[kind]`。`should_tick` 透传 weather。loop 已有 weather，穿进 should_tick。
- `map_data`：`location_is_indoor(loc_id)` = `loc["type"] != "outdoor"`（据 type 派生，偏差：不逐地点手标 indoor）。
- decide：rain/storm 且居民在户外 → 0.6 概率改道最近室内地点（新规则，`_maybe_shelter(ctx)`）；storm 加入 `_should_interrupt` 信号。
- 天气心情微项：rain/storm 每小时 `(-0.02,-0.01)`、sunny 晨间 `(+0.02,0)`——挂 `heat_cron`（hourly）。
- 测试：storm 活动概率 < sunny；躲雨改道触发；心情微项。

### Task 9: 星期与节日节律（§3.3）
- `build_schedule(sbti, weather=None, weekday=None)`：realism+周末（5/6）→ wake_hour+1、rest_ratio+0.1、social_slots+1。loop 传 `datetime.now().weekday()`。
- 节日：world_events 有 type=="festival" 活跃时，社交时段概率 +0.2、节日地点 VISIT_DISTRICT 权重 ×3（plan 候选/decide 权重）。
- 测试：同居民工作日/周末 schedule 差异。

### Task 10: 三需求底座（§4，单独提交批次，先写设计小结进 PROGRESS）
- `meta_json.needs = {energy,satiety,social}`（0–1 init 0.8）。`needs_service.py`（新）：`get_needs(resident)`、`metabolize(resident, activity, sbti)`（tick 代谢，读写 meta_json）、`apply_need(resident, key, delta)`、`most_critical(needs)`。
- 代谢挂 tick：`resident_tick` 开头（daily-limit 后、phase 前）调 `metabolize`，**不计入每日行动数**（在 phase chain 外）。walking 由 status 判定。
- 新 EAT 动作：`ActionType.EAT`；`get_available_actions` 加 EAT（需身处餐饮类地点 category=="dining"）；execute 处理 EAT（satiety += 0.5，纯状态）；`map_data` 地点加 `category`（cafe/tavern→dining）。
- 需求裁决层：`decide/basic.py` 在三条路径前，realism+任一需求<0.25 → 零 LLM 强制：energy→GO_HOME+置 sleeping（作息窗内醒）、satiety→最近 dining+EAT、social→CHAT 权重×2。优先级 < 高重要度计划强制执行、> plan-skip。
- prompt 注入需求摘要一行（decide/chat）。
- 顺手：夜归到家 idle→sleeping（`night_homing` / execute GO_HOME）。
- 测试：代谢速率、危急裁决触发、EAT 恢复、sleeping 进出、`realism off` == 现状。
