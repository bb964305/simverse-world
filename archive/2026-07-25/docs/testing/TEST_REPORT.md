## 2. 分模块结果

### M0 基础设施 — 全过(1 项缺陷见 P1-1)

API `/health` 200;前端及全部 96 个资源请求 200;TLS 双域名剩余 29 天(8/22 到期,**建议确认自动续期**);CORS 仅放行 `https://simverse.world`;`/metrics` 有 Bearer 保护;OpenAPI 146 路径正常。

### M1 认证与账号 — 除注销外全过

注册/登录/`/users/me`/错误密码 401/伪造 token 401/重复注册 409 全部正确;10 个受保护接口未带 token 全部 401/403;GitHub 与 LinuxDo OAuth 端点均正确 307 跳转到第三方授权页;注册限流 5/分钟生效(第 6 次 429);改密码闭环正确(旧密码立即失效)。**账号注销 500,见 P1-3。**

### M2/M3 角色与居民 — 全过

Onboarding 检查/创建角色/跳过引导正常;精灵模板 20 个;居民列表 16-19 个、详情含 SBTI/人设;角色卡、导出(own)、版本历史、目标、家装读取正常;越权测试正确:编辑/导出他人角色均 403;世界位置 33 个;按名搜索命中。

### M4 WebSocket 实时 — 全过

首消息 auth 鉴权 → `auth_ok` + `spawn_position`;伪 token 正确 close 4001;每日登录奖励 +10 SC 下发;双客户端移动广播、`online_players`/`player_joined` 互见、玩家私聊即时送达(对方自动回复模式也触发)全部正常。

### M5 NPC 对话与多模态 — 核心全过

- LLM 回复 3–7 秒返回,内容高度贴合 klaus 人设(理性主义者/星尘粒子研究);
- **三层记忆验证通过**:上一段对话植入暗号"蓝色的猫头鹰在钟楼下睡觉",结束会话后新开对话提问,NPC 准确复述暗号原文,还基于地图知识指出"中央广场没有钟楼"的逻辑矛盾——记忆写入、检索、与地图感知的融合都在工作;
- 评分、结束对话、会话历史正常;
- 图片上传成功(需 `media_type` 查询参数),但**上传后的静态 URL 404,见 P1-1**;发图给 NPC 的看图问答因此未能闭环验证(覆盖缺口,修复后需补测);
- TTS 未配置(接口明确报错,符合部署预期)。

### M6 锻造 Forge — 快速/引导过,深锻状态机有缺陷

快速锻造 ~70 秒完成,产出完整三层文档(persona/soul/ability),角色"夜风侦探"已入住世界并出现在公告栏"最新入住";引导锻造 start→status→answer 流转正常;AI 头像生成 200 返回 URL(但该 URL 同样受 P1-1 影响无法访问);精灵智能匹配返回合理模板。**深度蒸馏见 P1-2。**

### M7 经济系统 — 全过(重点回归项通过)

新账号初始 200 SC + 每日奖励;商店 10 件商品(字段 `price_sc`);购买 tip_5sc 后余额精确 196→191、库存与流水同步;**超额购买 400"Insufficient Soul Coins"且余额不变**;**5 路并发购买余额精确扣 25、无超卖无负数**——本次部署改动过的 `charge` 原子扣款路径验证通过。辩论/委托当前无进行中条目(接口正常,记 SKIP;世界里已有一场 NPC 自主辩论"村里该不该修一座钟楼"klaus vs mei 已结束)。

### M8 社交与内容 — 全过(2 项按设计澄清)

公告栏读取正常(热门居民榜实时反映了测试对话拉高的 klaus 热度 62);发帖 403"Admin privileges required"——**发公告是管理员专属,权限正确**(与方案假设不符,已澄清);时间胶囊补测通过(服务端强制"3 天~1 年"投递窗口,首测 +2 天被正确拒绝);关注/取关、关系图谱(24 条边)、日报/周报、通知已读、成就 12 项、每日任务、探索图鉴、创作者统计全部 200。赛季页"当前无进行中赛季",排行榜 404(前端优雅处理;建议改回 200 空列表,见 P2-2)。

### M10 管理后台 — 全过(安全)

### M11 Lab 实验模块 — 按配置禁用

`POST /lab/tasks` 返回 503 "Lab is disabled"(与 `LAB_ENABLED=false` 默认一致),余额不受影响;只读接口(researchers/tasks)返回 200 空列表。**注意:前端"实验楼"入口和发布表单完全可见可填**,用户提交时才会碰到 503——建议前端按配置隐藏或置灰(P2-1)。

### M12 居民自主行为 — ⚠️ 未在运行,需确认是否有意

40 分钟观察窗内 19 个居民的坐标、状态、`current_action` 零变化,`/feed` 恒为空,无新的居民间对话产生。这与 `.env.example` 中 "vm212 keeps AGENT_ENABLED false" 的注释一致,应是合规性考虑的有意配置;但 README 将"居民自主行为/自主对话"列为核心卖点,且 compose 里 agent-worker 容器在运行。**请确认生产是否应开启 `AGENT_ENABLED`;若本就关闭,此项不算缺陷。**(对照:对话热度、成就、天气事件等非 AgentLoop 链路都在正常工作。)

### M13 前端 E2E(真实 Chrome)— 全过

落地页/游戏页整页加载 96 请求全 200、控制台零 JS 错误;Phaser 世界完整渲染(tilemap、25 套精灵、小地图、天气横幅"多云"),在线玩家(含 API 测试创建的角色)实时可见;公告栏、赛季、辩论、商店、委托、实验楼各页面/面板全部正常打开;`/admin` 门禁有效。
