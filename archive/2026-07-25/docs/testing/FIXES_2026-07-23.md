## 一、修复内容

### P1-1 `/static/*` 全部 404(媒体上传、AI 头像不可访问)

**根因**:FastAPI 应用从未挂载 StaticFiles——任何 `/static/...` URL 必然 404;且 `MEDIA_UPLOAD_DIR` 默认值 `backend/static/uploads` 在 Docker 容器内(CWD=/app)落到 `/app/backend/static/uploads`,与头像目录 `static/portraits` 不在同一根下。

**修复**:
- `app/main.py`:挂载 `GET /static` → `settings.static_dir`(新配置,默认 `static`),启动时自建 `uploads/`、`portraits/` 子目录,配置错位时打警告日志;
- `app/config.py`:新增 `static_dir`,`media_upload_dir` 默认改为 `static/uploads`;
- `app/services/portrait_service.py`:头像目录改为从 `static_dir` 派生;
- `deploy/backend/docker-compose.yml`:api 服务新增 `media_static:/app/static` 卷,上传/头像跨重建持久化;
- `.env.example` 同步更新。**注意:若生产 `.env` 里显式设置了 `MEDIA_UPLOAD_DIR=backend/static/uploads`,请删除该行或改为 `static/uploads`。**

### P1-2 深度锻造状态机卡死(会话停在 building 40+ 分钟)

**根因**(三层叠加):
1. LLM 客户端未配置超时——Anthropic SDK 默认 600 秒/次 + 重试,一次挂住的中转调用可让一个阶段阻塞几十分钟(配置里的 `USER_LLM_TIMEOUT=120` 一直没接线);
2. `asyncio.create_task(...)` 未保存强引用,后台任务可能被 GC 悄悄取消,永远写不到终态;
3. 失败路径里若 DB 会话已被污染,写 `status=error` 的 commit 本身会再失败。

**修复**:
- `app/llm/client.py`:客户端工厂接线 `USER_LLM_TIMEOUT` / `USER_LLM_MAX_RETRIES`;
- `app/routers/forge.py`:后台任务持强引用;整条流水线加 15 分钟总超时;任何失败兜底写终态 `error`;`deep-status` 增加惰性清扫——非终态且 20 分钟未更新的会话在被查询时直接置为 `error`(覆盖进程重启丢任务的情况);
- `app/forge/pipeline.py`:异常分支先 rollback 再重取会话写终态。

### P1-3 账号注销 500

**根因**(两层):
1. `residents.creator_id` 建表时是 NOT NULL,而注销逻辑要把它置 NULL(孤儿化 NPC)→ PG 直接 IntegrityError;
2. `conversations` / `messages` / `transactions` / `forge_sessions` / `memories.related_user_id` 等外键子行未清理,直接 `DELETE users` 违反外键。SQLite 开发库默认不校验外键,所以只在生产 PG 上炸。

**修复**:
- 新迁移 `040_residents_creator_nullable`:`residents.creator_id` 改为可空(已在真实 PG16+pgvector 上跑通全链迁移验证);
- `app/services/settings_service.py::delete_account`:按依赖顺序清理(messages→conversations→transactions→forge_sessions→pending_messages;memories.related_user_id 置 NULL;residents.creator_id 置 NULL)后再删用户。已在真实 PG 上端到端验证(注销 200、旧 token/密码失效、NPC 成为无主孤儿)。

## 二、AGENT_ENABLED 生产开启(你要求的)

生产 `.env`(服务器上 `/opt/skills-world/deploy/.env`)目前应为 `AGENT_ENABLED=false`。开启:

```bash
ssh <你的服务器>
cd /opt/skills-world/deploy
sed -i 's/^AGENT_ENABLED=.*/AGENT_ENABLED=true/' .env   # 若无此行则追加 AGENT_ENABLED=true
```

无需单独重启:下面的部署命令会重建容器并加载新 env。AgentLoop 跑在 agent-worker 容器里,每个 tick 都会检查该开关。

**开启后注意成本**:居民自主行为会持续产生 LLM 调用,受 `BUDGET_GLOBAL_DAILY_USD`(当前默认 1.5 美元/天)三级降载保护;如需更活跃可同步调大。
