## 1. 这是什么建筑

小镇邮局——民政议案「在南苑空地兴建一座邮局」通过后落成的第一座**治理建筑**。功能定位:寄信、收件、时间胶囊的中转站。常驻工作者是邮差**骆小舟**(luo-xiaozhou,第 11 位居民),他每天在这里 WORK(投递到期时间胶囊),居民与玩家会寻径到入口。后端几何已生效(dynamic_locations),缺的只是画面上的建筑——目前那块地在主地图上还是纯草地。

## 3. 外形设计

### 3.1 风格铁律(全图统一,不许偏离)

- **32px 网格像素画,俯视角、无屋顶**:本图是 Smallville/The Ville 式画法——建筑直接露出内部,外墙用白色墙冠 + 灰色内壁立面表现(参考勘察图里两栋邻居建筑),**不要画带屋顶的封闭外观**。
- **只用现有 tileset 拼**,不引入新图片资产:墙体/地板用 `Room_Builder_32x32`,家具用 `interiors_pt1–pt5`,户外装饰用 `CuteRPG_*` 系列。资产许可见 `docs/art/A0-asset-provenance.md`,新建筑必须落在已登记资产范围内。
- 配色跟邻居走:白墙、暖木色地板、明快春绿草地;邮局可以用少量**红/邮政绿点缀**(邮筒、招牌、包裹)形成身份识别,但别整面墙刷红。

### 3.2 布局建议(5×7 格内,自上而下)

```
y100:  墙  墙  门口  墙  墙      ← 北墙,门开在 x=46(入口 tile 留空可走)
y101:  ── 服务大厅:柜台横放,柜台后是分拣区 ──
y102:  信格墙(pigeonhole 书架/置物架贴西墙)
y103:  分拣桌 + 散落的包裹/邮袋(中心,骆小舟的工位)
y104:  包裹货架(东墙),留出走道
y105:  小憩角:一把椅子 + 小桌(骆小舟喝水的地方)
y106:  南墙(封死,无后门)
```

要素清单(按优先级):**门口一只红色/深色邮筒**(放门外一侧或门内第一格,这是"邮局"最强的识别符号)、服务柜台、一面信件分格架(用书架/置物柜 tile 即可读作 pigeonhole)、分拣桌 + 包裹堆、包裹货架。地板用暖木色板材(与松风公寓同款即可)。有富余再加:墙上挂钟、告示板、绿植一盆。

### 3.3 建筑外部

门口(46,100)外那一格保持草地/踏步可走;可在门两侧各放一格装饰(灯、花、木牌)。**不要**给建筑加院墙或栅栏——bounds 全域都算"在邮局内",围死了会挡 NPC。西南角清树之后,界外的树林带原样保留,让建筑像是"在林边空地上盖出来的"。

## 4. 技术集成(动哪些层)

编辑 `tilemap.json` 以下图层,在用地矩形内铺 tile(GID 从现有 tileset 取):

- `Interior Ground`:室内地板;`Wall`:四面墙体(北墙 x=46 留门洞);
- `Interior Furniture L1/L2`:家具两层(L2 叠在 L1 上,如桌上物品);
- `Exterior Decoration L1/L2`:**清掉界内的树**,门外装饰放这里;
- `Foreground L1/L2`:如需墙冠压在角色身后的效果,参考邻居建筑的用法;
- `Collisions`:墙体与家具格全部加碰撞;**入口 (46,100) 与室内走道必须留空**,否则玩家进不去、NPC 会在门口抽搐。

**别动**:`* Blocks*` 系列功能层(Arena/Sector/World/Spawning/Special Blocks Registry)与 `maze.json`——那是后端语义层,这次纯视觉施工不碰。改完跑 `python3 docs/art/render_map_crop.py 34 90 66 118 preview.png`(在 tilemap 目录下)对照勘察图自查,再进游戏实走一遍:从道路走进门、走到分拣桌、走出来,全程不卡。

## 5. 验收清单

1. 渲染预览:建筑风格与两栋邻居无违和(墙冠、地板、家具密度相当);邮筒可见,一眼读出"邮局";
2. 入口 (46,100) 可走,室内动线连通,墙体/家具碰撞正确;
3. 界内无残留树木,界外植被未被误伤;
4. 只改了 §4 列出的图层;功能 Blocks 层与 maze.json 的 diff 为零;
5. `npm run build` 通过,游戏内实走录屏或截图留证。
